# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

This is a **pre-built static blog** deployed to GitHub Pages at `burgessjp.github.io`. The site was generated by **Hexo** using the **NexT.Muse** theme (v5.1.1) and contains ~32 Chinese-language blog posts about Android development (2016-2017).

**Important**: This repository contains only the generated static output — no Hexo source files (`_config.yml`, `source/`, `scaffolds/`, etc.) are present. There is no build step; the HTML/CSS/JS here is deployed as-is.

## Architecture

- **Generated site structure**: Year-based post directories (`2016/`, `2017/`), plus `/archives/`, `/categories/`, `/tags/` listing pages
- **CSS**: Single compiled stylesheet at `/css/main.css` (NexT theme output)
- **JS**: Modular scripts in `/js/src/` — motion effects (Velocity.js), Algolia search, Duoshuo comments, lazy loading, scrollspy
- **Libs**: Third-party dependencies in `/lib/` (jQuery, Velocity, Fancybox, Font Awesome, FastClick, Three.js)
- **Theme**: NexT.Muse scheme with sidebar navigation, animated transitions, and Chinese localization (zh-Hans)

## Content Categories

Android, Material Design, ORM, RecyclerView, Retrofit, RxJava, 插件化换肤 (plugin theming), 项目 (projects), 源码分析 (source code analysis)

## Making Changes

Since there's no build pipeline, edits to HTML/CSS/JS files are deployed directly on push to `master`. Be aware that regenerating the site from a Hexo source would overwrite any manual changes.
