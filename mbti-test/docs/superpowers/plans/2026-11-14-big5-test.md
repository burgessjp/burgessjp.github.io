# 大五专业版（big5.html）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 IPIP-NEO-120 大五人格专业版单文件应用（120 题、五域+30 facet T 分报告、方法学披露、墨蓝纸感视觉、与娱乐版互链）。

**Architecture:** 同娱乐版骨架：`big5.html` 三段标记（`SCORING-CORE` 纯计分 / `CONTENT-DATA` 题库+常模+文案 / app 块 DOM），三屏状态机 + localStorage（key `big5-test-state`）。

**Tech Stack:** vanilla JS + 内联 CSS，零外部资源；Node 断言 + Playwright E2E。

**Spec:** `docs/superpowers/specs/2026-11-14-big5-test-design.md`

## Global Constraints

- **数据溯源红线**：题目英文原文、计分键（题→facet、正反向）、常模 M/SD 必须从 IPIP 官方渠道（ipip.ori.org、Johnson 的 IPIP-NEO 页面）逐项拉取核对后写入；拉取失败即停下向用户报告，**禁止凭记忆编写**
- `big5.html` 零外部资源；禁止 fonts.googleapis.com；系统字体栈
- localStorage key `big5-test-state`，结构 `{v:1, phase, order, answers, index, result}`
- UI 挂稳定 `data-testid`：`screen-welcome/quiz/result`、`btn-start`、`likert-{1..5}`、`btn-prev`、`progress-label`、`report-domain-{O,C,E,A,N}`、`report-facet-{O1..N6}`、`btn-share`、`btn-restart`、`share-img`、`link-mbti`；`index.html` 侧新增 `link-big5`
- 计分：反向题 6−s；facet raw 4–20、域 raw 24–120；T = 50+10×(raw−M)/SD 保留一位小数；档位 T<30 很低 / 30–45 低 / 45–55 中 / 55–70 高 / >70 很高（45 与 55 含在「中」）
- 主色墨蓝 `#1f3a5f` 替换朱砂；其余纸感编辑风与娱乐版一致
- Conventional Commits，禁止 Co-Authored-By
- 每任务收尾跑 `node test/big5-scoring.test.mjs` 全绿再 commit

import { readFileSync } from 'node:fs';

const html = readFileSync(new URL('../big5.html', import.meta.url), 'utf8');

function loadBlock(marker, names) {
  const re = new RegExp(`<!--\\s*${marker}-START\\s*-->([\\s\\S]*?)<!--\\s*${marker}-END\\s*-->`);
  const m = html.match(re);
  if (!m) throw new Error(`marker ${marker} not found in big5.html`);
  const inner = m[1].replace(/<script[^>]*>/g, '').replace(/<\/script>/g, '');
  return new Function(`${inner}\n; return { ${names.join(',')} };`)();
}

let passed = 0;
function check(name, cond, detail = '') {
  if (!cond) { console.error(`FAIL: ${name}${detail ? ' — ' + detail : ''}`); process.exit(1); }
  passed++;
}

const { DIM5, FACETS, LIKERT5, bandOf, computeBig5, shuffle } =
  loadBlock('SCORING-CORE', ['DIM5', 'FACETS', 'LIKERT5', 'bandOf', 'computeBig5', 'shuffle']);

check('DIM5 五域', DIM5.join('') === 'OCEAN');
check('FACETS 每域 6 个', DIM5.every(d => FACETS[d].length === 6));
check('LIKERT5 五点', LIKERT5.length === 5 && LIKERT5[0].v === 1 && LIKERT5[4].v === 5);
check('bandOf 边界', bandOf(29.9) === '很低' && bandOf(30) === '低' && bandOf(44.9) === '低'
  && bandOf(45) === '中' && bandOf(55) === '中' && bandOf(55.1) === '高' && bandOf(70) === '高'
  && bandOf(70.1) === '很高');

// ── 计分数学 fixture（手算）──
// f1 正向, f2 反向（同 facet）；f3 正向（同 facet）
// answers: f1=5, f2=5(反→1), f3=4 → facet raw = 5+1+4 = 10；M=8, SD=2 → T = 50+10*(10-8)/2 = 60.0 → 高
const FX = [
  { id: 'f1', dim: 'O', facet: 'O1', rev: 0 },
  { id: 'f2', dim: 'O', facet: 'O1', rev: 1 },
  { id: 'f3', dim: 'O', facet: 'O1', rev: 0 },
];
const FN = { domains: { O: { M: 20, SD: 6 } }, facets: { O1: { M: 8, SD: 2 } } };
const r1 = computeBig5(FX, FN, { f1: 5, f2: 5, f3: 4 });
check('fixture facet raw=10', r1.facets.O1.raw === 10, `got ${r1.facets.O1.raw}`);
check('fixture facet T=60.0', r1.facets.O1.T === 60, `got ${r1.facets.O1.T}`);
check('fixture facet band=高', r1.facets.O1.band === '高');
// 域 raw = 同 3 题（fixture 无其余题）= 10；M=20, SD=6 → T = 50+10*(10-20)/6 = 33.3
check('fixture 域 T=33.3', r1.domains.O.T === 33.3, `got ${r1.domains.O.T}`);

// 反向钳制与缺省：f1=9→5；f2 缺省 3→反 3；f3=0→1
const r2 = computeBig5(FX, FN, { f1: 9, f3: 0 });
check('钳制/缺省/反向', r2.facets.O1.raw === 5 + 3 + 1, `got ${r2.facets.O1.raw}`);

check('确定性', JSON.stringify(computeBig5(FX, FN, { f1: 3 })) === JSON.stringify(computeBig5(FX, FN, { f1: 3 })));
const arr = [1, 2, 3, 4, 5, 6, 7, 8];
const before = arr.join(',');
const sh = shuffle(arr);
check('shuffle 守恒', arr.join(',') === before && sh.slice().sort().join(',') === '1,2,3,4,5,6,7,8');

console.log(`OK: ${passed} checks passed`);

- [x] **Step 3: 写 `big5.html` 骨架 + SCORING-CORE**

HTML 壳与样式先复制娱乐版结构（主色换墨蓝 `#1f3a5f`，`--seal` 更名 `--accent`）。SCORING-CORE 按 Interfaces 签名实现，算法与注释里的手算一一对应：

```js
function computeBig5(questions, norms, answers) {
  const facets = {}, domains = {};
  for (const d of DIM5) {
    let dRaw = 0;
    for (const f of FACETS[d]) {
      let fRaw = 0;
      for (const q of questions) {
        if (q.facet !== f) continue;
        const a = Math.max(1, Math.min(5, answers[q.id] ?? 3));
        const s = q.rev ? 6 - a : a;
        fRaw += s; dRaw += s;
      }
      const { M, SD } = norms.facets[f];
      const T = Math.round((50 + 10 * (fRaw - M) / SD) * 10) / 10;
      facets[f] = { raw: fRaw, T, band: bandOf(T) };
    }
    const { M, SD } = norms.domains[d];
    const T = Math.round((50 + 10 * (dRaw - M) / SD) * 10) / 10;
    domains[d] = { raw: dRaw, T, band: bandOf(T) };
  }
  return { domains, facets };
}
```

`bandOf`：`T < 30 ? '很低' : T < 45 ? '低' : T <= 55 ? '中' : T <= 70 ? '高' : '很高'`。
