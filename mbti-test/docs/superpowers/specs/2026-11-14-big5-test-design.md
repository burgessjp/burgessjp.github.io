## 1. 背景与目标

娱乐版 MBTI（`index.html`）保留不动。新增专业版：**基于大五人格模型（Big Five）的 IPIP-NEO-120 自评工具**，给想要有据可依结果的用户。

定位与上限（报告页明示）：IPIP 题库公有领域、学界效度证据充分；常模为美国成人样本（非中国常模）；译文为基于英文原文的自译（非回译校验版）；严肃自评工具，**非临床诊断工具**。

成功标准：

- 120 题完整流程可一口气完成（进度保存 + 恢复）
- 报告给出五域 + 30 子特质（facet）的 T 分、五档位、原创解读
- 方法学页完整披露来源、许可、常模局限、非临床声明
- 断网双击 `big5.html` 完全可用（零外部资源）
- 两版本入口互链可用（file:// 与静态托管均可）
- 手机 375px/320px 布局正常

非目标：

- 不做中国常模（没有公开可用的）
- 不做 MBTI↔大五映射
- 不做 60 题简版/双版本选择
- 不做后端、账号、历史记录对比

## 2. 模型与题库

- **IPIP-NEO-120**（Johnson, 2014 版），公有领域（IPIP 明确声明题库无版权限制，可自由使用、翻译、修改）
- 结构：5 域（开放性 O / 尽责性 C / 外向性 E / 宜人性 A / 神经质 N）× 每域 24 题 × 每域 6 facets × 每 facet 4 题
- 量表：5 点「自我描述准确度」——官方锚点 Very Inaccurate → Very Accurate，中文定稿：
  `1 非常不准确 / 2 比较不准确 / 3 既不准确也不不准确 / 4 比较准确 / 5 非常准确`
- 约一半题目反向计分（计分键由官方给出）
- **实施硬约束：题目英文原文、计分键（题→facet 映射 + 正反向）必须从 IPIP 官方渠道逐项拉取核对后才写入，不凭记忆**。拉取失败则停下向用户说明，不降级为凭记忆编写。
- **常模来源（2026-11-14 用户确认）**：单一来源 ipipneo.org / JobCannon IPIP-NEO-120 技术手册（CC BY 4.0，n=3,011–3,079，2026-10 版）。facet M/SD 直接取自该手册；域 M = 各 facet 均值之和 + 24，域 SD 由 SEM/√(1−α)×0.96 推导（同源推导，保证 facet 加总与域分内部自洽，此性质写入断言）。Johnson 原始 facet 常模因 PSU 站点不可达弃用；方法论页如实标注「常模为自选在线样本（n≈3,011，2026 年），非全国概率样本」。
- 中文译文：基于英文原文自译，口语可读但忠实原意（不意译成另一句话）；报告页注明译文性质

## 3. 计分与常模

```
题分 s ∈ {1..5}，反向题先反转为 6 − s
facet 分 = 该 facet 4 题之和                 → 4..20
域分     = 该域 24 题之和                    → 24..120
T 分     = 50 + 10 × (raw − M) / SD         # ipipneo.org/JobCannon 常模（见 §2 来源说明）
档位     <30 很低 / 30–45 低 / 45–55 中 / 55–70 高 / >70 很高
```

- **五档位与解读文案的关系**：报告展示五档位词（更细的刻度），但解读文案按三桶取用（高 ≥55 / 中 45–55 / 低 <45）——刻度细、文案粗，是有意设计，避免 15×5 档的文案爆炸

- 常模表数据项：5 域 + 30 facets 的 M/SD，共 35 项，写入 CONTENT-DATA，来源与版本在方法论页注明
- 计分纯函数：`computeBig5(questions, answers) → { domains: {O:{raw,T,band}, …}, facets: {O1:{raw,T,band}, …} }`，确定性、与展示顺序无关

## 4. 报告内容

- **五域总分**：条形（0–100 T 分标尺、50 处中线）+ T 数值 + 档位词 + 域级解读
  - 域级解读 3 档（高/中/低，按 T ≥55 / 45–55 / <45 取用）× 5 域 = 15 段原创中文
- **30 facets**：每域一节，域内 6 个 facet 的 T 分条 + 一句话解读
  - facet 解读 2 档（高分 ≥55 / 低分 <45；中档 45–55 显示中性说明一句）× 30 = 60 段高分/低分文案 + 1 段通用中档说明，原创中文
- **方法学页**（报告底部固定章节）：IPIP-NEO-120 来源与 Johnson 2014 版本、公有领域许可、译文为自译、常模为美国样本及其含义、五档位划分依据、非临床声明
- **分享卡片**：克制版——纸底墨蓝框、五域 T 分横条 + 档位，canvas 自绘 PNG，复用 Web Share / 长按保存 / 下载三路逻辑

## 5. 架构（复用娱乐版骨架）

- `big5.html` 单文件，同样的三段标记：
  - `SCORING-CORE`：`DIM5`（域序）、`FACETS`（域→facet 序）、`LIKERT5`（锚点定稿）、`computeBig5`、`shuffle`
  - `CONTENT-DATA`：`QUESTIONS`（120 题，含 facet、正反向键、中文译文、英文原文）、`NORMS`（35 项 M/SD）、`REPORT_TEXT`（域级 15 段 + facet 高低 60 段 + 中档说明）
  - app 块：三屏状态机、进度保存、分享卡片
- localStorage key `big5-test-state`，结构 `{v:1, phase, order, answers, index, result}` 与娱乐版同构
- 交互复用：一次一题、选中 200ms 自动前进、可回退、刷新恢复、重测清库
- **入口互链**：
  - `index.html` 欢迎页按钮下方加一行链接「想要更专业的？试试大五人格完整版 →」→ `big5.html`（相对路径）
  - `big5.html` 欢迎页对应位置「只想轻松玩？试试 MBTI 十六型人格 →」→ `index.html`
- 题目呈现顺序：实施时打乱（同娱乐版），计分按题目 id 索引不受顺序影响

## 7. 验证方案

**Node 断言**（`test/big5-scoring.test.mjs`，模式同娱乐版提取标记块）：

- 题库：共 120 题、每域 24、每 facet 恰 4、id 唯一、中文译文与英文原文均非空且各自唯一、反向题总数等于拉取官方键时记录的 `REVERSE_COUNT` 常量
- 常模表：35 项齐全（5 域 + 30 facet），数值类型合法
- 文案：15 域级段非空（长度阈值）、60 facet 段非空、中档说明存在
- 计分 fixture（手算小样本）：反向题反转正确、facet 求和正确、T 分换算正确（给定 M/SD 手算期望）、全选「既不准确也不不准确」→ 各 raw 为中性值、确定性
- 报告完整性：computeBig5 输出覆盖 5 域 + 30 facet 的 raw/T/band

**E2E**（`test/big5-e2e.py`，同 Playwright 框架）：

- file:// 打开 → 120 题全流程（固定作答模式，期望分数由 Node 断言先行锁定；E2E 断言报告页五域条、T 分与档位渲染）
- 进度推进到 120/120、刷新恢复、重测清库
- 互链：`index.html` → `big5.html` → 回链可达
- 分享卡片 data:image/png；320px 无横向溢出；无 JS 错误；零外链
