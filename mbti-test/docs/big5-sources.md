# big5.html 数据溯源记录

所有数据拉取与核对日期：2026-11-14。

## 1. 题目原文与计分键（权威源）

**来源**：<https://ipip.ori.org/30FacetNEO-PI-RItems.htm>
「The Items in Each of the 4-Item IPIP Scales Measuring Constructs Similar to Those in the 30 NEO-PI-R Facet Scales (Johnson, 2014)」——IPIP 官网收录的 Johnson IPIP-NEO-120 逐题表。

- 120 题英文题干（原句为接续句式的片段，如 "Worry about things."，呈现时按惯例补第一人称主语，计分不受影响）
- 每题 facet 归属（N1–N6 / E1–E6 / O1–O6 / A1–A6 / C1–C6）与正反向（+ keyed / – keyed）
- **反向题合计 55 / 120**，与两个独立第三方逐题核对一致：
  - JobCannon 技术手册明确记载 "Reverse-keyed items: 55 of 120"
  - knowthydefaults.com/methodology/items 逐题 keying 与官方页完全一致

计分约定（IPIP 标准）：+keyed 记 1–5，−keyed 反转（6−s）后求和。

## 2. 常模（用户确认的单一来源）

**来源**：<https://ipipneo.org/reliability>（域名镜像与数据来源：JobCannon IPIP-NEO-120 Technical Manual，edition 2026-10-23，CC BY 4.0）

- 样本：自选在线测试者 n=3,079（信度表）/ n=3,011（百分位表），2026-05-30 至 2026-10-23 收集；方法论页如实披露该样本性质
- **facet M/SD（30 项）**：直接取自信度表（原表 0–16 量程，本项目换算 +4 至 4–20 量程，SD 不变）
- **域 M/SD（5 项）**：同源推导
  - 域 M = Σ(该域 6 个 facet 的 4–20 量程 M) + 0（facet 已含 +4 偏移，直接求和即为 24–120 量程域 M）
    - O 86.6 / C 85.4 / E 74.0 / A 87.1 / N 68.1
  - 域 SD = SEM/√(1−α) × 0.96（原表 SEM 在 0–100 百分比量程，×96/100 换算到 24–120 量程）
    - O 11.72 / C 15.33 / E 15.03 / A 13.49 / N 16.64
  - 推导依据：SEM = SD×√(1−α) 为定义式；α 与 SEM 取自同表，故换算无损
- **内部自洽性**：域 M ≡ 该域 facet M 之和（本项目按推导值写入，断言精确校验此恒等式）
- 与 Johnson 21–40 岁合并组域常模（knowthydefaults.com/methodology 披露：O 87.38/12.40、C 86.53/14.07、E 79.84/14.93、A 88.06/12.25、N 69.56/16.32）对照：O/C/A/N 差 ≤1.5 分、SD 差 ≤0.7；E 域均值差 5.8（样本构成差异），因无法取得 Johnson facet 级常模、且混源会产生内部不自洽，弃用混合方案（2026-11-14 用户确认）
